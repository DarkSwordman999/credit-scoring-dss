«Разработка информационной системы поддержки принятия решений для оценки кредитоспособности физических лиц на основе методов машинного обучения»

Репозиторий — основа будущей дипломной работы. Сейчас в нём собраны результаты практических работ по курсу «Программная инженерия» (ТулГУ, ИПМКН). В этих работах для системы выполнены обследование и анализ осуществимости, сформулированы требования и ТЗ, построены функциональная и объектная модели и план проекта. Там же лежит первый прототип скоринговой модели. На этой базе дальше будет вестись разработка ВКР.

## Идея системы

Банк получает заявку на потребительский кредит. Система сама собирает данные: анкету, кредитный отчёт БКИ и сведения из АБС. Затем она проверяет стоп-факторы кредитной политики, рассчитывает показатель долговой нагрузки (ПДН) и оценивает **вероятность дефолта (PD)** моделью машинного обучения. На выходе сотрудник получает рекомендацию и рекомендуемые условия кредита, а также **объяснение**: какие факторы повлияли на оценку (SHAP). Решение остаётся за андеррайтером.

Ключевые компоненты:

| Подсистема | Назначение |
|---|---|
| Приём и учёт заявок | Анкета, документы, согласия, жизненный цикл заявки |
| Сбор и верификация данных | Интеграция с БКИ и АБС, стоп-листы, кредитное досье |
| Скоринг (ML-модуль) | Признаки, PD-модель, класс риска, ПДН, объяснение факторов |
| Поддержка принятия решений | Рекомендация, лимиты полномочий, кредитный комитет |
| Мониторинг и обучение моделей | Реестр версий, валидация, Gini / PSI, переобучение |
| Отчётность и администрирование | Отчёты по портфелю, роли, справочники, аудит |

## Подход к машинному обучению

- **Целевая переменная:** просрочка более 90 дней в течение 12 месяцев после выдачи.
- **Базовая модель:** логистическая регрессия на WoE-признаках, то есть классическая интерпретируемая скоринговая карта.
- **Основная модель:** градиентный бустинг (CatBoost / LightGBM).
- **Интерпретация:** SHAP-значения для каждой заявки.
- **Метрики:** ROC AUC, Gini, KS. Стабильность данных контролируется по PSI.
- **Особенности:** reject inference (смещение выборки из-за того, что исход известен только по одобренным заявкам), калибровка PD, мониторинг деградации модели.

Прототип: [`ml/baseline_scoring.py`](ml/baseline_scoring.py). Он работает на синтетических данных и сравнивает логистическую регрессию с бустингом.

```bash
pip install -r requirements.txt
python ml/baseline_scoring.py
```

## Структура репозитория

```
reports/     отчёты по практическим работам (DOCX + PDF)
diagrams/    диаграммы: IDEF0, IDEF3, VORD, ER, UML, сетевой график, Гант
ml/          прототипы моделей машинного обучения
tools/       генератор отчётов (python-docx + MS Word) — исходники текста и диаграмм
```

Отчёты собираются генератором из `tools/report_generator` (`python build.py`). Ему нужны Windows, MS Word, Java 11+ и [`plantuml.jar`](https://github.com/plantuml/plantuml/releases), положенный рядом со скриптами. Данные титульного листа задаются в `config.py`.
