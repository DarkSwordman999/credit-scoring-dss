# Кредитный скоринг Базовая — оценка кредитоспособности для небольшой кредитной организации

**Тема:** «Разработка информационной системы поддержки принятия решений для оценки кредитоспособности физических лиц».

Это ветка `coursework`, **базовая редакция** СППР «Кредитный скоринг», версия **1.1.1**. Небольшое веб-приложение на Python (Flask) и SQLite. Работает на одном компьютере, без сервера и без администратора. Полная редакция для отдела розничного кредитования банка находится в ветке [`main`](../../tree/main).

## Зачем отдельная базовая редакция

Так устроен рынок учётных программ: один продукт выпускается в нескольких редакциях под заказчиков разного размера. Например, у «1С:Розница» есть «Базовая» и «ПРОФ». Базовая рассчитана на одно рабочее место и не требует администрирования. ПРОФ нужна организации с несколькими сотрудниками и обменом данными с другими системами.

С кредитным скорингом то же самое. Небольшая микрофинансовая организация или кредитный потребительский кооператив — это один-два специалиста за одним ПК. Кредитный отчёт они получают на веб-портале бюро кредитных историй, автоматизированной банковской системы у них нет. Такой организации не нужны:

- **сервер PostgreSQL, Docker и отдельный сервис скоринга** — их надо устанавливать, обновлять, резервировать и защищать;
- **пять ролей, лимиты полномочий и кредитный комитет** — решение принимает тот же специалист, что принял заявку;
- **интеграция с АБС и Active Directory** — у организации нет ни того, ни другого;
- **реестр версий методики с утверждением и ежемесячным мониторингом** — для этого нужен риск-аналитик и тысячи выданных кредитов.

Для неё всё это — лишние затраты на внедрение и сопровождение (совокупная стоимость владения, TCO). Нанимать ИТ-специалиста ради программы она не будет.

Базовая редакция решает эту задачу:

- **не требует администрирования:** база данных SQLite — это один файл `creditdss.db` рядом с программой; резервная копия — копия этого файла;
- **работает на слабом ПК:** нужен только Python, памяти расходуется в разы меньше, чем у полной редакции;
- **работает без интернета:** всё нужное лежит в архиве релиза, включая пакеты для установки (папка `wheels`);
- **ставится за минуту:** распаковать архив и дважды щёлкнуть `run.bat`.

Ядро методики в обеих редакциях одно: стоп-факторы кредитной политики, показатель долговой нагрузки (ПДН), скоринговая карта с переводом балла в вероятность дефолта, класс риска, объяснение факторов, рекомендация и обязательное обоснование решения, если оно расходится с рекомендацией. Организация, которая выросла до отдела кредитования, переходит на полную редакцию.

## Что умеет

- **Заявка:**
  - анкета клиента;
  - параметры займа в пределах кредитного продукта;
  - сведения из кредитного отчёта БКИ: платежи по действующим кредитам, длина истории, просрочки, запросы в бюро;
  - согласие клиента на обработку данных и запрос в БКИ — без него заявку не рассматривают.
- **Стоп-факторы** — сразу отказ:
  - возраст меньше 21 года или больше 70 лет на дату погашения;
  - текущая просрочка;
  - ПДН больше 80 %;
  - доход ниже 15 000 руб.
- **ПДН** = (платежи по действующим кредитам + аннуитетный платёж по новому займу) / доход.
- **Скоринговая карта:** баллы по возрасту, стажу, доходу, ПДН, кредитной истории, просрочкам и запросам в БКИ. Вероятность дефолта: `PD = 1 / (1 + 50 · 2^((балл − 600) / 20))`. Классы риска: A — до 2 %, B — до 5 %, C — до 10 %, D — до 20 %, E — выше.
- **Рекомендация и условия по классу риска:** сумма может быть снижена, ставка — повышена. Плюс три фактора, сильнее всего повысивших риск, и три — снизивших.
- **Решение:** одобрить или отказать. Если решение не совпадает с рекомендацией, нужен комментарий не короче 20 символов.
- **Отчёт** за 30–365 дней: заявки, одобрения и суммы по классам риска. **Справочник** кредитных продуктов.

## Установка и запуск

Нужен Python 3.11 или новее ([python.org](https://www.python.org/downloads/), при установке отметить «Add python.exe to PATH»).

**Из релиза (без интернета).** Скачайте `CreditDSS-Basic-<версия>.zip` со страницы [Releases](../../releases), распакуйте и дважды щёлкните `run.bat`. При первом запуске программа создаст окружение, загрузит демо-данные и откроет браузер. Чтобы остановить программу, закройте окно консоли.

**Из исходников:**

```
cd app
python run.py                   # то же, что run.bat; пакеты ставятся из интернета
```

или вручную:

```
cd app
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
python demo.py                  # демо-данные: 3 продукта, 150 заявок за полгода
python app.py                   # http://127.0.0.1:5000/
```

Вход: `admin` / `admin`. Программа принимает подключения только с этого же компьютера (127.0.0.1). Ключ сессии хранится в `app/secret.key`; если файл удалить, программа создаст новый, и всем придётся войти заново.

Резервная копия — файл `app/creditdss.db`, его достаточно скопировать. `python demo.py` удаляет текущую базу и создаёт демонстрационную заново.

## Устройство

```
app/
  run.bat, run.py запуск: окружение, демо-данные при первом запуске, браузер
  app.py          страницы (маршруты Flask)
  logic.py        стоп-факторы, ПДН, скоринговая карта, PD, класс риска, рекомендация
  db.py           подключение к SQLite
  schema.sql      таблицы БД
  demo.py         демонстрационные данные
  templates/      HTML-страницы (шаблоны Jinja)
  static/         стили
```

Таблицы: `users`, `products` (кредитные продукты), `clients`, `applications` (заявка, оценка и решение).

## Версии

Релизы базовой редакции выходят из этой ветки с тегами `basic-v*` и не сливаются с `main`: у редакций своя нумерация и свой цикл выпуска. Релизы полной редакции — теги `v*` из `main`. Модели машинного обучения разрабатываются в ветке [`ml`](../../tree/ml).

- **1.1.1** — ключ подписи сессии создаётся случайным при первом запуске и хранится в файле `secret.key` рядом с программой; отладочный режим Flask выключен (включается переменной `FLASK_DEBUG=1`).
- **1.1.0** — таблицы, формы, окно входа и отбор заявок выровнены по центру страницы; заголовки и пояснения — тоже.
- **1.0.0** — первая версия базовой редакции: заявка, стоп-факторы, ПДН, скоринговая карта, класс риска, факторы, решение, отчёт; запуск через `run.bat` без интернета.
