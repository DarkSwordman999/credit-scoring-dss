СППР «Кредитный скоринг» — поддержка принятия решений по оценке кредитоспособности физических лиц
===================================================================================================

Запуск (установка не нужна)
---------------------------
1. Распакуйте архив в любую папку, например C:\CreditDSS.
2. Запустите КредитныйСкоринг.exe.
3. При первом запуске программа предложит загрузить демонстрационные данные — нажмите Enter
   (около минуты). Затем в браузере откроется http://127.0.0.1:8000/.
4. Не закрывайте чёрное окно, пока работаете: это сервер программы.

Вход
----
Администратор: admin / admin  (смените пароль: меню пользователя → «Профиль и пароль»).
Демо-пользователи, пароль demo:
  officer      — кредитный специалист (регистрация заявок, выдача)
  underwriter  — андеррайтер, лимит полномочий 1 000 000 руб.
  underwriter2 — андеррайтер, лимит полномочий 500 000 руб.
  head         — руководитель кредитного отдела (кредитный комитет, утверждение методики)
  analyst      — риск-аналитик (методика оценки, мониторинг, стоп-факторы)
Администратор видит этот список на главной странице и может войти под любой ролью.
Больше всего видит head: заявки, заёмщики, кредитный портфель, отчёты, таблицы БД.
Администратор заявки и данные клиентов не видит — это разделение полномочий.

Данные
------
Все данные лежат в папке data рядом с программой:
  data\creditdss.db  — база данных;
  data\documents     — прикреплённые копии документов;
  data\backup        — резервные копии (ежедневно в 02:00, хранятся 14 последних);
  data\secret.key    — ключ подписи входа, создаётся при первом запуске; не передавайте его.
Для переноса на другой компьютер скопируйте папку data целиком.

Команды
-------
  КредитныйСкоринг.exe demo --reset      — загрузить демо-данные заново (все данные удаляются)
  КредитныйСкоринг.exe backup            — резервная копия базы
  КредитныйСкоринг.exe restore <копия>   — восстановить базу из копии (программу закройте)
  КредитныйСкоринг.exe monitor 2026-09   — мониторинг методики за месяц
  КредитныйСкоринг.exe create-user ivanova пароль underwriter --name "Иванова А. А." --limit 700000

Настройки (переменные окружения или файл .env рядом с программой)
------------------------------------------------------------------
  CREDITDSS_PORT=8000                  порт веб-интерфейса
  CREDITDSS_HOST=0.0.0.0               доступ с других компьютеров сети
  CREDITDSS_SSL_CERTFILE=cert.pem      HTTPS: сертификат и закрытый ключ в формате PEM
  CREDITDSS_SSL_KEYFILE=key.pem
  CREDITDSS_DATABASE_URL=postgresql+psycopg://user:pass@host:5432/credit_db   работа с PostgreSQL
  CREDITDSS_LDAP_URL=ldap://dc.bank.local, CREDITDSS_LDAP_DOMAIN=BANK          вход через Active Directory

Описание API: http://127.0.0.1:8000/api/docs

Важно
-----
Программа не предназначена для принятия реальных решений о выдаче кредитов.
Демонстрационные клиенты, паспорта и кредитные истории вымышлены; бюро кредитных историй и АБС
в демо-режиме заменены встроенными имитаторами.
